# Deliverables

## Built in this repository

- `metadata/review_a_extraction.csv`
  - 29 cardiac seasonality and related cardiovascular papers
- `metadata/review_b_methods.csv`
  - 24 seasonality-method references
- `papers/pdfs/`
  - downloaded open-access PDFs where available
- `papers/review_a_extraction_pdf_manifest.csv`
  - access status for cardiac review papers
- `papers/review_b_methods_pdf_manifest.csv`
  - access status for methods papers retrieved so far
- `papers/repository_index.md`
  - quick index of included references
- `search/prisma_flow_counts.md`
  - PRISMA-style counts for the current build
- `search/screening_log.csv`
  - included-record screening log
- `notes/`
  - review summaries, access notes, and MRI analysis strategy
- `scripts/example_seasonality_model.py`
  - example phenotype-level seasonality test
- `overleaf/`
  - Overleaf-ready manuscript source
- `overleaf_project.zip`
  - uploadable Overleaf bundle

## Current blockers

- No supported local browser was available to create a cloud Overleaf project automatically.
- No local LaTeX engine was available to compile-check the manuscript in this environment.
- Many included papers are not openly downloadable via Europe PMC, so the PDF repository is currently partial.

## What is already actionable

You can already use this repository to:
- plan the MRI analysis
- start a manuscript or review write-up
- inspect the included literature
- upload the Overleaf project bundle manually
- extend the paper set once additional PDF access is available
