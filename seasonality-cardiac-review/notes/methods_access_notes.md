# Methods access notes

The methods review intentionally mixes:
- journal articles
- tutorial/review papers
- books / monographs

Because of that, a complete PDF mirror is harder than for a pure PubMed article set.

In practice:
- some article-level method references can be downloaded openly
- some are classic older papers behind journal paywalls
- several high-value references are books, so there is no single article PDF to mirror

Openly retrieved so far:
- M04 Stolwijk et al. 1999
- M07 Cornelissen 2014

For immediate analysis design, this is not a major blocker, because the key transferable methods are already identified and summarized in `metadata/review_b_methods.csv`.
