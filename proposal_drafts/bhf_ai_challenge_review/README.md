# BHF AI challenge review workspace

This folder contains an expanded literature, policy, and market-review scaffold for the BHF Cardiovascular Grand Challenge AI theme, built from the preliminary abstract supplied in Slack plus public sources.

## Artifact map

### Reproducible build

- `scripts/build_tables_and_bibliography.py` - reproducible build that consumes the intermediate JSONs and emits the master citations, BibTeX, and evidence tables. Run with `python3 scripts/build_tables_and_bibliography.py`.
- `scripts/build_site.py` - existing site builder for the local web view.

### Source-of-truth data

- `data/evidence.json` - structured evidence records with PMIDs, quotes, hard numbers, tags, URLs, and local source-copy paths.
- `data/intermediate/ai_ecg_candidates.json` - 62 AI-ECG study candidates (PMID/DOI).
- `data/intermediate/ai_cmr_candidates.json` - 46 AI-CMR study candidates.
- `data/intermediate/llm_cv_ai_clinic_candidates.json` - 28 LLM / AI-clinic / trial candidates.
- `data/intermediate/curated_extensions.json` - 78 curated foundational and policy references for the broader corpus.
- `data/intermediate/ai_ecg_query_results.json`, `ai_ecg_raw_*` etc. - raw harvested content (kept for reproducibility but not consumed by the build).
- `data/knowledge_graph.json` - relationship graph used by the local web view.

### Generated citation system

- `refs/references.bib` - 233 unique BibTeX entries with stable citation keys.
- `data/master_citations.json` - canonical record per citation, including bibtex text, PMID, DOI, topic tags, source origin, modality, validation status, etc.
- `data/tables/citation_index.csv` - flat searchable index over the master citations.

### Evidence tables

Generated by the build script in three formats per table:

- `data/tables/ai_ecg_top50.{csv,md,tex}` - Top 50 AI-ECG studies prioritised by trial design, external validation, and deployment relevance.
- `data/tables/ai_cmr_table.{csv,md,tex}` - 51 AI-CMR studies covering segmentation, diagnosis, scar/fibrosis, outcomes, workflow, and multicentre validation.
- `data/tables/ai_clinic_trials_table.{csv,md,tex}` - 72 AI-in-clinic entries including completed and ongoing trials, registry studies, LLM workflow studies, and concrete deployment papers.

### Notes (long-form synthesis)

- `notes/literature_review.md` - original expanded review.
- `notes/extensive_review_llm_and_ai_in_cardiovascular_care.md` - longer synthesis using the full master corpus, with explicit maturity-vs-weakness map.
- `notes/ai_clinic_trials_review.md` - completed and ongoing trial / deployment evidence.
- `notes/multi_agent_synthesis.md` - five-agent reading (clinical methodologist, implementation/policy, AI engineering, PPI, BHF reviewer) with synthesis.
- `notes/cross_agent_disagreement_red_team.md` - adversarial reading recording residual disagreements and how the proposal should respond.
- `notes/background_tightened_for_overleaf.md` - compact paste-ready background section.
- `notes/bhf_tailoring_notes.md` - BHF call-specific positioning notes.
- `notes/reviewer_1_clinical_methodology_red_team.md` - aggressive reviewer checklist.
- `notes/reviewer_2_implementation_policy_red_team.md` - aggressive reviewer checklist.
- `notes/source_inventory.md` - inventory of locally saved source files.
- `notes/research_passes/` - per-pass harvest notes for AI-ECG, AI-CMR, and LLM/CV/AI-clinic.

### Local web view

- `web/` - searchable local webpage and knowledge graph assets.

### Source documents

- `docs/raw/webpages/` - downloaded copies of cited webpages, including policy pages and commercial AI-ECG product pages.
- `docs/raw/pdfs/` - downloaded PDFs for the BHF call and related guideline material.
- `docs/raw/publications/` - downloaded PubMed source pages for cited publications.

## Overleaf project

The Overleaf-ready project lives outside this folder at `../../tmp_overleaf_bhf/`:

- `main.tex` - top-level document, inputs the section files and uses the BibTeX bibliography.
- `sections/background.tex` - background, clinical use cases, AI-ECG / AI-CMR sections, LLMs, translation/policy, and proposed framing - all citing BibTeX keys.
- `sections/evidence_tables.tex` - compact illustrative evidence tables for ECG, CMR, and clinic / trials.
- `references.bib` - copy of `refs/references.bib`; refresh via the build script.

## How to refresh

```bash
python3 scripts/build_tables_and_bibliography.py
cp refs/references.bib ../../tmp_overleaf_bhf/references.bib
```

The build is idempotent and uses `pmid > doi > normalized title` order for dedupe.

## Source note

The Overleaf project was not directly readable from this environment during initial collection, so the review was produced from:

- the preliminary abstract text provided in Slack

- public policy and guideline webpages
- PubMed-indexed literature
- official commercial AI-ECG product pages

## Current positioning recommendation

The strongest framing is:

- one *generalisable decision platform*
- three exemplar cardiovascular decisions: intervention, surveillance, follow-up
- AI-ECG as a scalable *input and phenotyping layer*
- AI-CMR as a deep *phenotyping layer* for the chosen exemplars
- LLMs only as a *supervised communication and workflow layer*
