# CHD USA 2026 dossier

This dossier collects congenital heart disease statistics for the United States for the VESPA grant application.

## Target outputs
- Overleaf-ready report in `reports/overleaf/main.tex`
- Web summary in `site/index.html`
- PMID-backed evidence entries in `evidence_template.yaml`
- Reproducible search provenance in `search_log.md`

## Key metrics
- Cases / prevalence
- Annual incidence or births affected
- Deaths / mortality
- Survival rates
- Surgery counts and procedure classes
